# 管道探测小车 · 数字孪生平台

基于 Unity 的管道探测小车数字孪生系统，连接真实小车（树莓派），实时接收管道检测数据、激光雷达点云与摄像头图像，在 Unity 中重建管道三维模型并标注缺陷，同时反向下发运动控制指令。

## 功能特性

- **数字孪生可视化**：虚拟小车实时映射真实小车的运动与姿态
- **管道三维重建**：激光雷达点云逐帧累积，重建管道内壁网格
- **缺陷检测标注**：结合摄像头识别结果，在点云中标红缺陷位置
- **双向通信**：WebSocket 接收小车数据、下发控制指令；TCP 接收摄像头图像
- **自动巡航扫描**：云台 360° 往复旋转扫描，自动换向

## 快速开始

1. 用 Unity 2022 打开本项目
2. 场景中放入小车模型（标签设为 `Player` 或 `ModelCar`）
3. 点击运行，系统自动装配所有组件并生成 UI
4. 无真实硬件时可用键盘控制小车，雷达显示模拟回波

## 操作说明

| 操作 | 功能 |
|------|------|
| W / S | 小车前进 / 后退 |
| A / D | 小车左转 / 右转 |
| 鼠标右键拖动 | 环绕相机旋转视角 |
| 鼠标滚轮 | 缩放视角 |
| E（按住）| 手动旋转云台 |
| 左侧栏「驾驶模式」| 切换手动 / 自动巡航，调节云台转速 |

## 通信协议

### WebSocket（小车 ↔ Unity）

**小车 → Unity**（`StatusPacket`）：管道参数、检测结果、base64 图像、激光雷达点云

**Unity → 小车**（`ControlPacket`）：

```json
{
  "wheel_motor_speed": 0,
  "camera_motor_speed": 0,
  "drive_mode": "manual",
  "direction": 1,
  "throttle": 0,
  "speed": 0
}
```

- `camera_motor_speed`：摄像头电机转速（度/秒），自动巡航时带正负号表示方向
- `drive_mode`：`manual` 或 `auto`

### TCP（摄像头 → Unity）

8 字节包头（`length:int` + `type:int`）+ 数据体，`type=1` 为 JPEG 图像，`type=2` 为识别结果 JSON。

## 自动巡航云台往复扫描

自动巡航模式下，云台以 UI 设置的速率旋转，**每转满 360° 自动反向**，循环往复扫描管道内壁。下位机收到的 `camera_motor_speed` 会带方向（正转正、负转反）。

├── UI/              # HUD 界面、模式控制、雷达、曲线图
